# Security Policy

## Supported versions

Only the latest release published on the [Releases](https://github.com/kveld9/trackGym/releases) page receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/kveld9/trackGym/security/advisories/new). Do not open a public issue or pull request for a security problem.

Include:

- the affected app version and Android version;
- steps to reproduce, or a proof of concept;
- the impact you observed (for example, data exposure through backups, exports or Health Connect sync).

Do not include real personal workout or body data in the report.

## Response

- Acknowledgement within 7 days.
- A fix or mitigation plan within 30 days for confirmed issues, released as a new version.
- Credit in the release notes, unless you ask to stay anonymous.

## Scope

In scope: the TrackGym app code in this repository, its local data storage, import/export and backup features, and the release APKs published here.

Out of scope: vulnerabilities in Android itself, in third-party libraries without a TrackGym-specific impact, and devices that are rooted or otherwise compromised.
